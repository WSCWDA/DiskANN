Mixed hash is default; legacy is a process-lifetime control, never change policy while a coordinator contains entries. Both shard selection and unordered_map hash use the selected hash. No change to allocation, critical section, completion or retention. Optional per-query shard counters aggregate after search; no shared profiling atomics. Lock wait/hold include acquire and publish shard mutex operations, hold excludes unlock itself; publish hold includes state mutex. Profiling adds clocks and per-query storage (64*48 bytes per query even when disabled); compare performance with profiling off.
