# P3.2-B1
CMS cumulative, 64 independent shards, uint32 saturating counters, depth 4 default, 1 MiB total counter payload. Row hashes mix both offset and length with row-specific seeds. No aging or shadow exact in production. Exact remains default. Configuration must be set before Coordinator construction and remain immutable. Counter payload excludes allocator/object overhead. Clear resets counters without reallocating.
Run unit test and microbenchmark with g++ -std=c++14 -O2 -pthread -Iinclude. Run scripts/qshape/run_frequency_sketch.sh with fresh OUT and standard dataset variables; validate with scripts/qshape/validate_frequency_sketch.py --out "$OUT" --repeats 3. This is a B1 smoke matrix, not B2 capacity sweep. Microbenchmark is single-thread uniform per-shard, not full concurrent evaluation. Additional saturation/concurrency/multi-victim tests, shadow diagnostics and exact allocator accounting remain pending.
