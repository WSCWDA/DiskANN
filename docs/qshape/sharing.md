# P2 in-flight sharing MVP
Reader-instance scoped exact offset/length sharing, enabled only inside measured query scope. Includes rerank reads if present; reader_requests is the conservation denominator, not logical_node_reads. No READY retention. Owners submit all owned and bypass reads before publishing and waiting. Copy into original aligned scratch preserves existing consumption order. Payload budget counts pinned buffers until last reference; metadata excluded. 64 shards, nonblocking budget fallback. Same-query joins reported separately. Lookup includes lock/allocation; wait_copy combines wait and copy. Peak is reader lifetime high-water mark. Partial submission drains accepted reads then throws; short reads propagate; unrecoverable harvest failure aborts rather than releasing live DMA memory. OpenMP exception boundary remains fail-fast (not graceful per-query recovery). No device-level counters, no separate lock/wait/copy timing, no owner-linked trace yet. Tests cover synthetic cycle, budget, no retention and failure publication; target build and sanitizer/real I/O fault injection pending.
